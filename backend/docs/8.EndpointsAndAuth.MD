## 8. Testing endpoints and auth
1. Registering an admin User
```
mutation RegisterAdmin {
  register(input: {
    name: "Admin User"
    email: "admin@example.com"
    password: "SecurePass123!"
    captchaToken: "turnstile-token"
  }) {
    token
    user {
      id
      name
      email
      role
      createdAt
    }
  }
}
```

2. Registering a normal user
```
mutation RegisterUser {
  register(input: {
    name: "Regular User"
    email: "user@example.com"
    password: "UserPass123!"
    captchaToken: "turnstile-token"
  }) {
    token
    user {
      id
      name
      email
      role
      createdAt
    }
  }
}
```

3. Create a script to convert a user to admin
backend/src/scripts/makeAdmin.ts
```
npx ts-node src/scripts/makeAdmin.ts admin@example.com
```

4. Login as admin 
```
query Me {
  me {
    id
    name
    email
    role
    lastLogin
  }
}
```

Then, in the browser app, authenticated requests use the secure httpOnly auth cookie set by `login` or `register`.
