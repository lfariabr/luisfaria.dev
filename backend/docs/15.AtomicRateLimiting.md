# Atomic Rate Limiting with Lua Scripts

`src/middleware/rateLimiter.ts` - Atomic rate limiting implementation using Redis for distributed rate limiting.

Current usage is applied in the chatbot mutations `src/resolvers/chatbot/mutations.ts` under `askQuestion`.

## Problem: Race Condition in Rate Limiting

### Non-Atomic Pattern (❌ Old Implementation)
```typescript
// Step 1: GET current count
const count = await redisClient.get(redisKey);
const currentCount = count ? parseInt(count, 10) : 0;

// Step 2: CHECK limit
if (currentCount >= limit) {
  return { success: false };
}

// Step 3: INCREMENT
await redisClient.incr(redisKey);

// Step 4: SET EXPIRY
if (currentCount === 0) {
  await redisClient.expire(redisKey, expiry);
}
```

**Race Condition Scenario:**
```
Request A: GET count=4
Request B: GET count=4
Request A: CHECK 4 >= 5? NO ✓
Request B: CHECK 4 >= 5? NO ✓
Request A: INCR → count=5
Request B: INCR → count=6  ⚠️ LIMIT EXCEEDED!
```

**Impact:** Under concurrent load, rate limits can be bypassed by 2x or more.

---

## Solution: Atomic Lua Script

### Why Lua?
- **Atomic execution**: Redis executes Lua scripts without interruption
- **Single round-trip**: Reduces network latency from 4+ calls to 1
- **Server-side logic**: Eliminates race conditions entirely

### Implementation

```lua
local key = KEYS[1]
local limit = tonumber(ARGV[1])
local expiry = tonumber(ARGV[2])

local current = tonumber(redis.call('GET', key) or '0')

if current >= limit then
  local ttl = redis.call('TTL', key)
  return {0, 0, ttl}
end

local newCount = redis.call('INCR', key)

if newCount == 1 then
  redis.call('EXPIRE', key, expiry)
end

local ttl = redis.call('TTL', key)
local remaining = limit - newCount

return {1, remaining, ttl}
```

**Execution Flow:**
1. ✅ GET current count atomically
2. ✅ CHECK limit atomically  
3. ✅ INCREMENT if allowed atomically
4. ✅ SET EXPIRY if first request atomically
5. ✅ RETURN result atomically

**All operations execute in a single atomic transaction on Redis.**

## TypeScript Integration

```typescript
export class RateLimiter {
  private luaScript: string;

  async limit(key: string, limit: number, expiry: number): Promise<RateLimitResult> {
    const redisKey = `${this.prefix}${key}`;
    
    // Execute Lua script atomically
    const result = await redisClient.eval(this.luaScript, {
      keys: [redisKey],
      arguments: [limit.toString(), expiry.toString()],
    }) as number[];

    const [success, remaining, ttl] = result;
    const resetTime = new Date(Date.now() + ttl * 1000);

    return {
      success: success === 1,
      limit,
      remaining,
      resetTime,
    };
  }
}
```
