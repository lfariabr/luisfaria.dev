**Acceptance criteria:**

- [x] Home tests + build green

---

## Overview

Follow-up to v3.14. The hero subtext was long and largely restated the metric cards directly below it. On mobile that extra height pushed the metrics row down into the floating action buttons (Apod/Goggins/Stripe FABs, fixed bottom-right), so a FAB overlapped a metric card. Tightening the subtext to one concise sentence shortens the hero on mobile, lifting the metrics clear of the FAB stack.

## Problem

- Subtext duplicated the metric cards → vertical bloat on mobile.
- The taller hero pushed the metrics row into the fixed FAB zone → overlap.

## Changes

- **`content/profile.ts`** — `POSITIONING.subline` shortened to:
  > I turn messy, manual work into automated, KPI-driven systems — data, full-stack, and ML. 10+ years end-to-end; now at St Catherine's, Sydney.
- Hero-only; no FAB/layout refactors (the FABs are unchanged — the shorter hero is what clears the overlap).
