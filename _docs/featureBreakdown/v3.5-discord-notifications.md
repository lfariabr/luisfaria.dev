## Overview
Expanded real-time Discord webhook coverage across all major user interaction touchpoints. Previously only 3 events fired notifications with generic messages. Now 7 events fire with rich contextual messages.

## Problem
The existing Discord notifications (`"Login button was clicked"`, `"Register button was clicked"`) were opaque — they confirmed the button was pressed but gave no context about who. Additionally, significant user interactions (APOD, Stripe, Goggins) had no visibility at all.

## Design Decision: `void` over `await`
Switched from `await sendDiscordWebhook(...)` inside a try/catch to `void sendDiscordWebhook(...)`. This makes all notifications truly fire-and-forget — the UI proceeds immediately regardless of webhook latency or failure. The discord utility already handles errors internally via the logger.
