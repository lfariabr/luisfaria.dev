## Overview

Copy-only rewrite of the homepage's four proof surfaces — hero metrics, "What I do" pillars, "Core stack" pills, and "Impact" stats — replacing insider shorthand with 2026 proof points a recruiter can decode in one pass. All components unchanged; only content files touched.

## Problem

- The 4 hero stat blocks were insider shorthand a stranger couldn't decode ("~4h saved / per term rollover · St Cath", "5 models / compared by MAE · CRISP-DM", "$12/mo / infra, production-grade") and undersold recent wins.
- "What I do" pillar blurbs were generic capability claims with no evidence.
- "Core stack" had ~30 pills, diluting the signal of the tools that actually matter.
- "Impact" led with weak stats instead of the strongest numbers (2,000-user pentested portal, 1M+ records, 30K+ msgs/mo).

## Changes

### 1. `frontend/src/content/profile.ts`

**`HERO_METRICS` replaced** — four new decodable proof points:
- `10+ yrs` / building software, data & AI systems end-to-end
- `2,000 users` / pentested portal, shipped solo in 8 weeks *(accent moved to this card)*
- `30K+` / messages automated every month
- `1M+` / client records managed in production

**`PILLARS` blurbs rewritten evidence-first:**
- Software: portal serving 2,000 parents (pentested, shipped solo in 8 weeks).
- Data: reverse-engineering legacy ETL estates.
- Automation: 100-minute batch job cut to ~2s; deploy downtime 10+ min → ~2s.
- AI/ML: applied ML with honest metrics + 1,100+ commit open-source agentic pipeline. Tags trimmed 7 → 5: `scikit-learn`, `FastAPI`, `OpenAI`, `Claude`, `RAG / agents`.

**`STACK_GROUPS` trimmed ~30 → 22 pills**, signature tools only:
- Software: TypeScript, React, Next.js, Node.js, GraphQL, Python
- Data: SQL Server, PostgreSQL, Power BI, Apache Superset, pandas, Redis
- Automation: unchanged
- AI/ML: scikit-learn, OpenAI, Claude, RAG, Claude Code / agents

### 2. `frontend/src/content/metrics.ts`

**`METRIC_GROUPS` rebuilt** into three groups, strongest first:
- **Scale:** 2,000 parents · 1M+ records across 20+ clinics · 30K+ WhatsApp msgs/mo
- **Reliability & security:** 0 cross-account leaks at 100-concurrent load · external OWASP pentest passed · 500+ automated tests behind CI gate
- **Efficiency:** 100 min → 2 s batch job · ~2 s deploy downtime · 11 → 0 manual query edits per finance cycle

### 3. `frontend/src/__tests__/app/Home.test.tsx`

Stack-only pill assertion updated `'Express'` → `'pandas'` (Express was trimmed from the stack).

> **Note:** Sensitivity rule honored — parent-portal stats are de-identified: no school name, person names, or hostnames appear in any new string, matching the published dev.to case-study posture.
