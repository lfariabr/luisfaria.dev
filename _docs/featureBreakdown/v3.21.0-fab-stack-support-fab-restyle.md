# v3.21.0 — FAB Stack and Support FAB Restyle

## GitHub Issue

**Issue:** [#312](https://github.com/lfariabr/luisfaria.dev/issues/312) (part of epic [#311](https://github.com/lfariabr/luisfaria.dev/issues/311))

**Title:** `feat(support): FAB stack and Support FAB restyle (v3.21.0)`

**Summary:**
The Support FAB is pinned at `bottom-[7.5rem] right-6` so it would sit above the APOD FAB, but the APOD FAB was taken out of the layout in e13858b. It now floats about 120px up with nothing under it. It also looks foreign to the site: an 80px amber button with a constant ping, on a site whose accent is emerald on stone neutrals. This ticket adds a FAB stack and restyles the Support FAB and its dialog to match the site.

## Acceptance Criteria

- [ ] A FAB stack component renders at the bottom-right and the Support FAB sits in its corner (no `bottom-[7.5rem]` offset)
- [ ] `ApodFab` and `GogginsFab` no longer set their own fixed position and stack correctly when rendered in the FAB stack
- [ ] Support FAB is ~56px, stone with an emerald ring, amber coffee icon, no constant ping
- [ ] `StripeDialog` uses stone/emerald tokens; no amber gradient line or amber selected state
- [ ] Support FAB stays hidden on `/notes`
- [ ] Opening the Support FAB still fires `stripe_fab_opened` and the Discord ping
- [ ] Works in light and dark themes and on mobile
- [ ] Frontend tests updated (`Stripe.test.tsx`) and a FAB stack test added; lint 0 warnings

## Overview

First of three Support checkout tickets. Floating buttons move into one FAB stack at the bottom-right, so placement no longer depends on which other buttons happen to be enabled, and the Support FAB plus its dialog pick up the site's stone/emerald tokens. Frontend only.

## Problem

1. **Misaligned Support FAB.** `StripeFab.tsx` uses `fixed bottom-[7.5rem] right-6` to clear the APOD FAB. `ApodFab` is no longer rendered in `layout.tsx`, so the Support FAB floats with empty space under it.
2. **Fixed per-FAB offsets.** `ApodFab.tsx` and `goggins/GogginsFab.tsx` each use `fixed bottom-6 right-6`. Re-enabling either means hand-tuning offsets again.
3. **Off-brand look.** The Support FAB is 80px (`h-20`), amber, with a constant `animate-ping`. The site accent is emerald on stone (`globals.css`, radius 0.625rem). The pulse also competes for attention on every page.
4. **Dialog matches the FAB, not the site.** `StripeDialog.tsx` uses an amber gradient line and an amber selected state.

## Changes

### 1. FAB stack (new component)
A single `fixed bottom-6 right-6` flex column (`flex-col-reverse` or `justify-end`, with a gap) rendered from `layout.tsx`. It holds whichever FABs are active; the Support FAB is the last child so it sits in the corner. APOD and Goggins slot in above it when re-enabled, with no offsets.

> **Note:** Proposed path `frontend/src/components/layouts/FabStack.tsx`, next to `Header`/`Footer`/`MainLayout`. Confirm during implementation.

### 2. `frontend/src/app/layout.tsx`
Render `<FabStack>` with `<StripeFab />` inside it. Keep `<GogginsFab />` commented out, but move the commented line inside the stack so re-enabling is a one-line change.

### 3. `frontend/src/components/stripe/StripeFab.tsx`
- Drop `fixed bottom-[7.5rem] right-6`; positioning comes from the FAB stack.
- Restyle: neutral stone button (`bg-card`/stone tokens) with an emerald ring, coffee icon as the one warm (amber) accent, ~56px (`h-14 w-14`).
- Remove the constant `animate-ping`. A hover/focus ring is enough.
- Keep the `/notes` hiding, the `stripe_fab_opened` analytics event and the "FAB opened" Discord ping.

### 4. `frontend/src/components/stripe/StripeDialog.tsx`
Replace the amber gradient line and amber selected state with stone/emerald tokens (emerald border/ring for the selected product). Products, amounts and the optional email field are unchanged.

> **Note:** The client-side "checkout initiated" Discord ping is removed in v3.21.1 (#313), not here, so the server-side replacement lands in the same change.

### 5. `frontend/src/components/apod/ApodFab.tsx`, `frontend/src/components/goggins/GogginsFab.tsx`
Remove their own `fixed bottom-6 right-6` so they behave as FAB stack children. Neither is rendered today, so there is no visible change.

### 6. Tests
- Update `frontend/src/__tests__/components/Stripe.test.tsx` for the new markup (no ping class, still hidden on `/notes`, analytics + Discord on open).
- Add a FAB stack test: renders children in sequence, Support FAB last.
