# v3.22.0 — Admin Shell Rework

## GitHub Issue

**Issue:** [#318](https://github.com/lfariabr/luisfaria.dev/issues/318) (follow-up: [#319](https://github.com/lfariabr/luisfaria.dev/issues/319) dashboard redesign)

**Title:** `feat(admin): admin shell rework — mobile drawer, grouped nav, back to site (v3.22.0)`

**Summary:**
The admin shell is broken on mobile and has no way back to the public site. This ticket adds a mobile top bar with a hamburger drawer, groups the nav into Content / Business / Personal, adds back-to-site links and a theme toggle, and removes the dead Settings link.

## Acceptance Criteria

- [ ] Below `md`, the sidebar is hidden and a top bar shows a hamburger + the current page title
- [ ] The hamburger opens a left `Sheet` drawer with the same grouped nav; choosing an item navigates and closes the drawer
- [ ] Nav is grouped into Content / Business / Personal under group labels; active state still works (Dashboard exact match, others prefix match)
- [ ] The brand and a "View site" footer item both link to `/` in the same tab
- [ ] The theme toggle (light/dark/system) is in the sidebar footer
- [ ] No link to `/admin/settings` remains anywhere in admin
- [ ] Tests: drawer opens and closes on navigation, active state inside groups, back-to-site links point to `/`, no settings link

## Overview

First of two admin tickets. This one fixes the shell (`AdminLayoutClient.tsx`); the dashboard redesign follows in v3.22.1. The admin area is treated as a **personal hub**: content, business and personal tools sit side by side, and it's often opened on a phone.

## Problem

1. **No mobile nav.** The layout is `flex-col md:flex-row` with a `w-full` aside, so on mobile all 8 links plus Logout stack above the content and push every page below the fold.
2. **No way back to the site.** The "Admin Dashboard" title isn't a link and there's no "view site" item.
3. **Flat, mixed nav.** Content (Projects, Articles), operations (Users, Payments) and personal tools (Pins, EMOM) are in one ungrouped list.
4. **Dead link.** Settings → `/admin/settings` doesn't exist (404). The dashboard's "User Role" card links there too.

## Changes

### 1. `frontend/src/components/ui/sheet.tsx`
Add shadcn `Sheet` (Radix Dialog based: focus trap, Esc and overlay close).

### 2. `frontend/src/app/admin/AdminLayoutClient.tsx`
- Nav defined as groups:
  ```
  [luisfaria.dev brand → /]
    Dashboard
  CONTENT    Projects · Articles
  BUSINESS   Payments · Users
  PERSONAL   Pins · EMOM
  ────────
    View site ↗   (same tab)
    Theme toggle
    Logout
  ```
- One `AdminNav` rendered in both the desktop aside (`hidden md:flex`, fixed `w-64`) and the mobile `Sheet`.
- Mobile top bar (`md:hidden`): hamburger + current page title, derived from the active nav item.
- Drawer closes on navigation (link `onClick`, plus closing on `pathname` change).
- Active state: Dashboard exact match, others `startsWith`.
- Settings item removed.

### 3. `frontend/src/app/admin/page.tsx`
Remove the "User Role" stat card (it links to `/admin/settings`). The rest of the dashboard is left for v3.22.1.

### 4. Tests (`frontend/src/__tests__/`)
- Hamburger opens the drawer; clicking a nav item closes it
- Active item inside a group (e.g. `/admin/articles/new` → Articles)
- Brand and "View site" link to `/`
- No `/admin/settings` link rendered

## Decisions

| Decision | Why |
|---|---|
| Own admin shell, not the public `Header` | Two stacked navs get messy on mobile; the theme toggle is the only thing worth carrying over |
| Hamburger + left `Sheet` drawer | Standard admin pattern; scales to grouped items better than a bottom tab bar; Radix gives a11y for free |
| Mobile top bar shows the page title | With the nav hidden, the title tells you where you are |
| Back to site on both the brand and a footer item, same tab | The brand link is what people expect, the explicit item is easy to find; new tabs pile up |
| Remove Settings rather than build it | A page without a job is what made the dashboard random; add it back when something real needs to live there |
| No collapsible desktop sidebar | 7 grouped items fit fine; collapse adds state and tests for no real gain |
