## Overview

The homepage hero led with a single static framing ("I solve real business problems with software and data."). It read one-dimensional and didn't signal the role range recruiters scan for. The hero now leads with a stable anchor — **"I build systems"** — plus a green clause and a lens pill that crossfade through four framings (ML → Data → Full-Stack → Hybrid), landing on the canonical **"Hybrid → that pay for themselves."** SEO and a11y are preserved: the semantic `<h1>` stays a static, server-rendered canonical phrase; the rotating layer is decorative.

## Problem

- One static framing couldn't speak to ML, Data, and Full-Stack audiences at once.
- The subline and proof strip were clinic/Konquista-era and not value-led.
- All three CTAs had equal weight — the live ML demo (AI assistant) didn't pull the eye.

## Changes

- **`useRotatingText` hook (new)** — cycles a frame index on an interval; SSR-safe (`useState(start)`), respects `prefers-reduced-motion`, cleans up on unmount. No new dependency.
- **`HeroHeadline` component (new, `'use client'`)** — renders the lens pill + `<h1>`. Crossfade uses a **CSS grid-stack** (all frames overlap in one cell) → true opacity crossfade and zero layout shift, no min-height guessing. `<h1>` exposes a static `sr-only` canonical phrase; the visual layer + pill are `aria-hidden`.
- **`content/profile.ts`** — new `HERO_CANONICAL_PHRASE`, `HERO_FRAMES`, `HERO_CANONICAL_INDEX`, `HERO_METRICS`; refreshed `subline`; removed the old `proof` strip data.
- **`app/page.tsx`** — hero now renders `<HeroHeadline />`, a 4-card metrics row (replacing the proof strip), and CTAs with the AI-assistant link given visual priority (2px emerald ring + emerald text + tint).
