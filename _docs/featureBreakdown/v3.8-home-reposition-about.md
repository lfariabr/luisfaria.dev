---

## Overview

Repositions the site around *"I solve real business problems with software and data"* and introduces a real About page. Replaces the "Senior Software Engineer" framing (which undersold the data/automation/AI work) with four equal pillars, and centralizes the curated content in `frontend/src/content/`.

## Problem

- Home led with "I build end-to-end systems… Senior Software Engineer", underselling **data, automation, and AI** — the strongest, most current parts of the story (data role at St Catherine's, MSWE+AI, automation/DevOps).
- The flat 18-item Core Stack list communicated breadth but no shape.
- The header dropdown linked to `/profile`, a page that **didn't exist** (404).
- No dedicated About page; the narrative was scattered across Home/Timeline.

## Changes

### 1. Curated content — `frontend/src/content/profile.ts` (new)
Single source of truth: `POSITIONING` (badge/headline/subline/proof), `PILLARS` (the 4), `STACK_GROUPS` (stack regrouped by pillar), `ABOUT_BIO`, `SOCIALS`.

### 2. Home — `frontend/src/app/page.tsx`
- New hero: badge `Engineer · Data · Automation · AI`, headline *"I solve real business problems with software and data."*, the new subline, and a **proof strip**.
- CTAs: **See my work** (`/work`), **About me** (`/about`), **Try my AI assistant** (`/chatbot`).
- New **"What I do"** 4-pillar block and **stack-by-pillar** block (replaces the flat list).
- JSON-LD `jobTitle` → `Software & Data Engineer`; description updated.

### 3. New sections — `PillarsSection.tsx`, `StackSection.tsx`
Reusable, content-driven; shared by home + about.

### 4. About — `frontend/src/app/about/page.tsx` (new)
Narrative bio, a "Currently" card (St Catherine's data work + Master's framed as applied: AWS architecture, Apache Superset BI, OpenAI tooling), pillars, stack, and social links. Metadata + Person JSON-LD.

### 5. Nav — `Header.tsx`, `Footer.tsx`
- Nav: `Home · Work · Projects · Articles · About` (Chatbot demoted to a hero CTA + footer link).
- Removed the dead `/profile` dropdown item (404 fix).
- Footer tagline + nav updated to match.

### 6. SEO — `sitemap.ts`
Added `/about` to the static routes.

### 7. Cleanup
Deleted the now-orphaned `frontend/src/utils/data.tsx` (its `CORE_STACK` moved into `content/profile.ts`).
