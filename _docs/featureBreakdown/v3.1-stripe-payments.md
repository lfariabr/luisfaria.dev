## Goal

Add a public Stripe checkout flow so visitors can:
- Buy me a coffee (AUD 5)
- Book a meeting (AUD 150)

UX must mirror the APOD pattern:
1. Global floating CTA button
2. Transparent selection dialog
3. Redirect to Stripe Checkout
4. Return to success/cancel pages

---

## Architecture

### Checkout path

`StripeFab` → `StripeDialog` → GraphQL mutation `createCheckoutSession(input)` → backend Stripe service → Stripe hosted checkout URL → redirect.

### Product model

Hardcoded keys (server-side validated):
- `coffee`
- `meeting`

Price IDs are injected from env:
- `STRIPE_COFFEE_PRICE_ID`
- `STRIPE_MEETING_PRICE_ID`

### Security model

- Stripe secret key is backend-only (`STRIPE_SECRET_KEY`)
- Mutation is intentionally public (support flow does not require auth)
- Server controls valid `productKey` and checkout session creation
