## GitHub Issue

**Issue:** [#239](https://github.com/lfariabr/luisfaria.dev/issues/239)

**Title:** `feat(content): repurpose /work into curated Case Studies (Phase 2, slice 2a)`

**Description:**
The home page promises case studies and versatility, but `/work` was still the old tabbed projects+articles list. This repurposes `/work` into curated, `problem → approach → stack → outcome` **case studies** — the deep-dives recruiters actually read.

**Acceptance criteria:**
- [x] `/work` shows case-study cards; each links to a `/work/<slug>` detail page
- [x] `npm run build` + `tsc --noEmit` clean; tests green

---

## Overview

Turns `/work` into a curated Case Studies section (curated in code), with an index of cards and per-case-study detail pages. Projects and writing remain at `/projects` and `/articles` (linked from the `/work` footer).

## Problem

- `/work` was a tabbed projects+articles list — the word "Work" was better spent on **case studies**.
- The new home positioning promises deep, outcome-led work; there was nowhere to land it.

## Changes

### 1. Curated content — `frontend/src/content/caseStudies.ts` (new)
Typed `CaseStudy[]` with `problem · approach · stack · outcomes · links`. Three studies, grounded in real public material:
- **St Catherine's — Data systems** (capabilities + tools level; SQL Server pipelines + Power BI).
- **AWS cloud architecture** (Master's: secure, scalable design for a 10× surge).
- **Apache Superset BI** (Master's: self-hosted BI on Azure + AWS, RBAC, deployment friction).

Master's studies link to the open-source `masters-swe-ai` repo (1,100+ commits).

### 2. `/work` index — `frontend/src/app/work/page.tsx`
Repurposed from the GraphQL tabbed list to static case-study cards; footer link to `/projects` and `/articles`. `CollectionPage` JSON-LD.

### 3. `/work/[slug]` detail — `frontend/src/app/work/[slug]/page.tsx` (new)
`generateStaticParams` (statically prerendered) + per-slug metadata + `Article` JSON-LD. Renders problem / approach / stack / outcome / links.

### 4. SEO — `work/layout.tsx`, `sitemap.ts`
Layout metadata → "Case Studies". Case-study URLs added to the sitemap.

### 5. Cleanup
Removed the now-orphaned `WorkTabsContent.tsx` and `ArticleCard.tsx` (`ProjectCard.tsx` kept — still used by `/projects`).
