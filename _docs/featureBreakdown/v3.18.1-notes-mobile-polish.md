## Overview

Three small fixes found on-device after the v3.18.0 mobile overhaul.

## Problem

1. **Truncated stats** — the 4-up "At a glance" tiles are ~75px wide on a phone; uppercase tracked labels `Checkpoints` and `Next moves` rendered as `CHECKP…` / `NEXT M…`.
2. **Dead title suggestion** — the placeholder read `Weekly update` with no way to accept it, and an empty title saved as an undated `Weekly update`.
3. **Week/Month overflow** — the period view's grids had no explicit column template below `lg`, so grid items kept `min-width: auto`. A long `whitespace-nowrap` badge set the card's min-width and pushed the entire page wider than the viewport (header visibly squeezed to ~60%). `truncate` on the `inline-flex` Badge never produced an ellipsis because text-overflow doesn't apply to an anonymous flex item.

## Changes

### 1. Stat labels
`Checkpoints · Wins · Weekly · Next moves` → `Notes · Wins · Weekly · Plans`. Every label is ≤ the width of `WEEKLY`, which already fit.

### 2. Dated title autofill
`buildSuggestedTitle(periodType, dateInputValue)` in `NoteForm.tsx` returns `Weekly update 05/10/2026` / `Monthly update 30/09/2026`, built from the **Checkpoint date** field (defaults to today, D-0; follows the date if backdated).
- Shown as the title placeholder.
- A one-tap **Autofill** button next to the label fills it; hidden once the title matches.
- Used as the saved title when the field is left empty.

### 3. Week/Month overflow
- `grid-cols-1` (`minmax(0, 1fr)`) on the outer and per-group grids, `min-w-0` on group sections and titles.
- Badge text wrapped in `<span className="truncate">` so long items end in `…`.
- Tighter card/section padding below `sm`.
