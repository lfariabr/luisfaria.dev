## Overview

Promotes the career timeline to a dedicated `/timeline` page (data extracted to `content/timeline.ts`), adds a `/contact` page, adds **Review Pulse** (a multi-domain review-sentiment ML classifier) as a 4th case study, and updates the README highlights for the new positioning.

## Changes

### 1. Timeline — `content/timeline.ts` (new), `TimelineSection.tsx`, `/timeline/page.tsx` (new)
- Extracted the hardcoded timeline into curated data (`TIMELINE`), with related-project links as chips.
- `TimelineSection` now consumes it and supports `limit` / `showHeading` / `showViewAll`.
- Home shows the **4 most recent** entries + a "View full timeline" link; `/timeline` shows the full history with its own heading + intro.

### 2. Contact — `/contact/page.tsx` (new)
Email-first CTA + GitHub / LinkedIn / dev.to / Master's-repo buttons + location, reusing `SOCIALS`. (A contact form via the backend Resend integration is a possible follow-up.)

### 3. Review Pulse case study — `content/caseStudies.ts`
4th case study: an ML pipeline classifying product-review sentiment across four retail domains (~8,000 labelled reviews), built with scikit-learn / pandas / Jupyter following CRISP-DM. Links to the `review-pulse` and `masters-swe-ai` repos. Gives the AI/ML pillar a concrete, hands-on artifact.

### 4. Nav + SEO — `Footer.tsx`, `sitemap.ts`
Footer nav gains Timeline + Contact. `/timeline`, `/contact`, and the new case-study URL added to the sitemap.

### 5. README
"Highlights for reviewers" refreshed: software & data positioning + a Case Studies entry.
