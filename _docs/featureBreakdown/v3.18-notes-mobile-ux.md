# v3.18 — My Notes Mobile UX

## GitHub Issue

**Issue:** [#293](https://github.com/lfariabr/luisfaria.dev/issues/293)

**Title:** `My Notes: mobile UX overhaul (iOS zoom, compact stats, line-based input, month accordion)`

**Summary:**
The private `/notes` workspace was built desktop-first. On a phone the page kept zooming in and bouncing back while filling the form, the "At a glance" card pushed notes below the fold, list fields only accepted comma-separated input, and every card rendered fully expanded in one endless timeline.

## Overview

A mobile pass over the logged-in My Notes area: fix the iOS zoom bounce, compress the hero, make list entry line-based, and fold older notes into a month/year accordion.

## Problem

1. **Zoom bounce** — iOS Safari auto-zooms on focus for any field under 16px. `Textarea` and `SelectTrigger` used `text-sm` (14px); `Input` already used `text-base md:text-sm`. A live audit at 375px confirmed there was **no horizontal overflow**, so the bounce came from focus-zoom, not layout.
2. **Oversized stats** — "At a glance" was a full card with a header and four 3xl tiles; labels like `ACCOMPLISHMENTS` with wide tracking overflowed their tiles.
3. **Comma-only list input** — `parseCsv` split on `,`, so real entries like `Double shift (Tue, Wed, Thu)` were saved as three items.
4. **Endless timeline** — all notes rendered as fully-expanded flashcards in one grid.
5. **Collapsed bullets** — list dots had no `shrink-0`, so they squashed into thin bars on wrapped lines.

## Changes

### 1. iOS focus-zoom fix
`Textarea` and `SelectTrigger` now use `text-base md:text-sm`, matching `Input`. Site-wide effect: any form using these primitives stops zooming on iOS.

### 2. Compact "At a glance"
Replaced the card with a `<dl>` stat strip: 4-up single row on mobile (`Checkpoints · Wins · Weekly · Next moves`), 2×2 on desktop. Hero padding, title size, badge and description scaled down below `sm`. The redundant hero view-toggle and the "All periods visible" pill are hidden on mobile (the segmented control already covers it).

### 3. Line-based list input
`parseListInput` (exported from `NoteForm.tsx`):
- Multi-line input → one item per line, commas preserved.
- Single-line input → comma-separated fallback.
- Leading `- `, `• `, `* ` bullet markers stripped (a bare `-5kg` is kept).

Edit form prefills accomplishments/plans one per line, so items round-trip exactly.

### 4. Month/year accordion
`NotesTimelineView` groups notes via `groupNotesByMonth` into sections labelled `March 2026 · 3 checkpoints · 20 wins`. The latest month opens by default, others collapse; `expandAll` (wired to an active search) opens everything. Uses an accessible `button` with `aria-expanded`/`aria-controls`.

### 5. Bullet fix
`shrink-0` and an aligned top offset on `NoteCard` list dots.
