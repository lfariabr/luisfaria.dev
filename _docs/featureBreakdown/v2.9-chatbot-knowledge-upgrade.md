# v2.9 — AI Chatbot Knowledge Base Upgrade

## Overview

Upgraded the portfolio chatbot's knowledge base from a sparse 9-article metadata-only profile to a rich 20-article context with summaries, tech stacks, and structured prompt engineering. The chatbot can now answer content-aware questions about articles, reference the 2026 career milestone, and present Luis's career as a coherent progression narrative.

## Problem

- `luis-profile.json` had only 9 article entries with title/date/platform — no content summaries
- The 2026 Data Analyst role at St Catherine's School Sydney was missing from experience
- System prompt dumped raw JSON into the model context with minimal instructions
- Chatbot couldn't answer questions like "Tell me about the CI/CD pipeline article" or "What's Luis doing now?"

## Changes

### 1. Enriched `luis-profile.json`

**File:** `backend/src/data/luis-profile.json`

| Before | After |
|--------|-------|
| 9 articles (metadata only) | 20 articles with `summary`, `tech[]`, `term` |
| No 2026 experience entry | St Catherine's Data Analyst role added |
| `current_focus` referenced Master's only | Reflects Data Analyst role + Master's |
| No SQL Server in skills | `T-SQL` in languages, `SQL Server` in databases |
| No GitHub Actions in devops | `GitHub Actions` added |

**Article coverage by term:**
- **t1_2026** (4): CI/CD Pipeline, SQL Server, South B Insights, myRoster
- **t2_2025** (11): Wedstack, Concierge, MongoDB vs Supabase, AWS Architect, CBA Challenge, ClinicTrends AI, QR Code Generator, Daily Follow-Up, 30-Min Automation, Konquista, CuraNexus Analytics
- **t3_2025** (5): Security Incident Report, Tata GenAI, IRL System, EigenAI, NPS Research

### 2. Improved System Prompt

**File:** `backend/src/services/openai.ts`

- Added `buildProfileContext()` that structures the profile into readable sections (Bio, Career Timeline, Projects, Articles, Skills, Education) instead of dumping raw JSON
- System prompt now instructs the model to:
  - Reference specific articles by title when relevant
  - Present the career as a progression: agency TPM → healthcare SE → data analyst + Master's
  - Use concise markdown formatting (bullets, short paragraphs)
  - Decline gracefully when questions fall outside the profile
- Cache mechanism preserved (`cachedProfile` pattern unchanged)

### 3. Content Sync Script

**New file:** `backend/scripts/sync-profile-articles.ts`

A utility script that reads all `.md` files from `_docs/devTo/` subdirectories and extracts:
- Title (first `#` heading)
- Tags (from `Tags:` / `Hashtags:` lines)
- Summary (first substantive paragraph, truncated to 3 sentences)

**Usage:**
```bash
npx ts-node backend/scripts/sync-profile-articles.ts
```

Outputs JSON to stdout for review before manually updating `luis-profile.json`. The hand-curated summaries in the profile are higher quality than auto-extracted ones, so the script serves as a discovery tool rather than a direct replacement.
