**Attachment:** course completion certificate (Packt)

Finished the course "Master Next.js by Building Scalable Apps with Routing, Databases, and Performance"!

Along the way I built a full-stack e-commerce app from scratch:
- Admin: Prisma + JWT auth, product/user CRUD, and a reports dashboard with charts
- Storefront: cart + Stripe embedded checkout, every sale persisted securely

The parts worth keeping went past syntax: small client component boundaries, never trusting the client (re-fetch prices from the DB, never send a password hash to the browser), and leaning on typescript to catch bugs before users do.

These days producing code is cheap. Making sure quality code is produced is where the value is.
