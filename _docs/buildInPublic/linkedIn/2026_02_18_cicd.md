I built a CI/CD pipeline on a $12/month DigitalOcean droplet, and it deploys in under 5 minutes. 

Here's what the full flow looks like:
1. git push to master triggers parallel Jest tests (backend + frontend)
2. On pass, Docker builds both images and pushes to GHCR with :latest and :sha tags
3. SSH deploy step pulls fresh images to the droplet
4. docker compose up --force-recreate brings everything live with ~2 seconds downtime
5. Health check runs post-deploy where a pass gets a Discord notification, fail triggers automatic rollback to the previous version

The stack running behind it:
- Next.js frontend on :3000
- Node.js + Apollo GraphQL backend on :4000
- MongoDB + Redis
- NGINX with SSL on :443

No Kubernetes. No $200/month managed services. Just solid fundamentals, docker compose, and github actions doing exactly what they're supposed to do.
