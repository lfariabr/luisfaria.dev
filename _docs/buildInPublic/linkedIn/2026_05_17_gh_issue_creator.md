The way I keep LLMs on a tight leash: structured issue breakdowns.

Concept → planning doc → GitHub issues → executor agent. Each issue has a Goal, Scope, and Acceptance section. The agent has no room to drift.

The missing piece was always step 3. Hand-creating 30 GitHub issues from a planning doc is copy-paste, typos, and duplicates by issue 15.

So I built a Python CLI that does it in one command. Markdown in, GitHub issues out. Dry-run by default. No install required — pure stdlib, one curl.

Full write-up + repo in the comments.
